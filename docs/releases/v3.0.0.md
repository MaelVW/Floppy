## Floppy Hub 3.0.0 – der erste richtige Release

Nach der Beta-Phase (2.0.0-beta.1 bis beta.6) ist Floppy Hub jetzt **Version 3.0.0**, keine Vorabversion mehr.
Hier alles, was die App heute kann – und was seit beta.6 dazukam.

### Neu seit 2.0.0-beta.6

- **Sperren im Offenen Chat lassen sich jetzt jederzeit aufheben** (Issue #5): Ein Gesperrter bleibt still
  verbunden – er sieht nichts und kann nichts schreiben –, damit er die Aufhebung oder das Ablaufen der Sperre
  mitbekommt. War er beim Aufheben nicht im Raum, fragt er beim nächsten Start still nach; der Admin antwortet.
  Abgelaufene Sperren enden von selbst.

### Das ist Floppy Hub 3

- **Disketten starten**: Steam-Spiele, Programme von der Diskette oder vom PC, Hub-Menü, Minispiel. Neues wird einmal
  nachgefragt, Bekanntes startet sofort (Vertrauensliste mit Prüfsumme; `C:\Windows` bleibt immer gesperrt).
- **Bibliothek, Bespielen, Laufwerke-Ansicht** mit Disketten, USB-Sticks, Speicherkarten, Festplatten, CD/DVD/Blu-ray;
  bis zu zwei zusätzliche Laufwerke neben `A:` überwachbar.
- **Chat**: Ende-zu-Ende verschlüsselt, online oder im lokalen Netz, ID-Nummern, Kontakte, Rangliste, **Schach**,
  **Offener Chat** mit **Admin-Kennzeichnung „(Admin)“** und **Moderation** (Sperren mit Grund und Dauer).
- **Minispiel „Diskettenlager“** mit Level-Editor (Farben, begrenzte Reichweite), Rekorden und eigenen Leveln.
- **Automatisches Update**: „Jetzt aktualisieren“ lädt das Setup selbst vom offiziellen Release (Prüfsumme wird
  kontrolliert), installiert es im Hintergrund und startet Floppy Hub neu. Die Update-Prüfung läuft auch bei
  länger laufender App (alle 45 Minuten und beim Öffnen des Fensters).
- Hell-/Dunkelmodus, Deutsch/Englisch, Pixel-Art-Oberfläche im Stil klassischer Windows-Programme.
- Die **Konsolen-Variante** (PowerShell, wie Version 1) bleibt unverändert und wählbar.

Ausführliche Anleitung und Entwickler-Doku im [Wiki](https://github.com/MaelVW/Floppy/wiki).

### Gut zu wissen

- Sperren im Offenen Chat hängen an der ID: Wer sich eine neue ID anlegt, kommt wieder hinein. „(Admin)“ und Sperren
  wirken nur bei Version 2.0.0-beta.5 oder neuer.
- Das Setup ist noch nicht signiert; Windows kann beim ersten Ausführen eine Warnung zeigen.
- Das automatische Update gibt es ab Version 2.0.0-beta.6 (und nur bei einer per Setup installierten App). Von älteren
  Versionen einmal das Setup von Hand ausführen.

### Installation

1. `FloppyHubSetup-3.0.0.exe` herunterladen und ausführen
2. Schon installiert? Setup einfach erneut ausführen – Einstellungen und Bibliothek bleiben
3. Unbeaufsichtigt: `FloppyHubSetup-3.0.0.exe /VERYSILENT /VARIANT=app` (oder `console`)

### Voraussetzungen

- Windows 10 / 11 (64 Bit)
- Konsole: Windows PowerShell 5.1 (bei Windows dabei)
- Diskettenlaufwerk als `A:` (USB-Floppy genügt) – oder bis zu zwei Wechseldatenträger als Ersatz

Die Prüfsumme der EXE steht in der beiliegenden `.sha256.txt`.
