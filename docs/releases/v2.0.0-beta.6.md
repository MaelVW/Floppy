## Floppy Hub 2.0.0-beta.6 – Automatisches Update

### Neu seit 2.0.0-beta.5

- **Update mit einem Klick**: Statt zur Webseite zu gehen und das Setup selbst herunterzuladen, gibt es im
  Hinweis jetzt „Jetzt aktualisieren“. Floppy Hub lädt das Update dann selbst herunter (mit
  Fortschrittsanzeige), installiert es im Hintergrund und startet sich danach neu – Einstellungen,
  Kontakte und Bibliothek bleiben erhalten. „Was ist neu?“ öffnet die Release-Seite.
- **Sicherheit**: Automatisch geladen wird nur vom offiziellen Release dieses Repositorys (https, github.com,
  genau diese Version), die SHA-256-Prüfsumme aus dem Release muss vorhanden sein und stimmen, sonst wird
  nichts installiert. Bei Problemen bleibt der Weg über die Release-Seite.
- **Der Update-Hinweis kommt jetzt auch, wenn die App schon länger läuft**: Bisher wurde nur beim
  Programmstart geprüft – wer Floppy Hub tagelang geöffnet ließ, hat neue Versionen nie gesehen. Jetzt
  wird beim Start, danach alle 45 Minuten und beim Öffnen des Fensters geprüft (mit kurzer Pause zwischen
  den Anfragen, ein fehlgeschlagener Start-Check wird bald wiederholt).
- Die Update-Prüfung wählt die höchste Versionsnummer statt einfach den ersten Eintrag der Liste.
- Das Setup startet die App (und den Launcher, falls er lief) nach einem automatischen Update wieder.

### Gut zu wissen (Beta)

- Das automatische Update gibt es nur bei einer per Setup installierten App und dem eingebauten GitHub-Feed.
  Der Schritt von beta.5 auf beta.6 geht noch von Hand (Setup herunterladen), ab beta.6 dann automatisch.
- Das Setup ist noch nicht signiert; Windows kann beim ersten Ausführen eine Warnung zeigen. Beim
  automatischen Update wird das Setup unbeaufsichtigt gestartet.

### Installation

1. `FloppyHubSetup-2.0.0-beta.6.exe` herunterladen und ausführen
2. Schon installiert? Setup einfach erneut ausführen – Einstellungen und Bibliothek bleiben
3. Unbeaufsichtigt: `FloppyHubSetup-2.0.0-beta.6.exe /VERYSILENT /VARIANT=app` (oder `console`)

### Voraussetzungen

- Windows 10 / 11 (64 Bit)
- Konsole: Windows PowerShell 5.1 (bei Windows dabei)
- Diskettenlaufwerk als `A:` (USB-Floppy genügt)

Die Prüfsumme der EXE steht in der beiliegenden `.sha256.txt`.
