## Floppy Hub 2.0.0-beta.2 – Update zur Pre-Release

Kurzes Update zu 2.0.0-beta.1 – kein neuer Funktionsumfang, sondern ein paar
Verbesserungen aus dem ersten Testlauf.

### Neu seit 2.0.0-beta.1

- **Offener Chat statt Debug-Chat**: der standardmäßig offene Chatraum ohne eigene
  Verschlüsselung heißt jetzt „Offener Chat" und ist ein dauerhafter Einstieg zum
  Reinschnuppern – kein Entwickler-Feature mehr, das vor einem Release abgeschaltet werden muss
- **Update-Hinweis**: die App prüft beim Start selbst, ob eine neuere Version da ist,
  und fragt nach („Herunterladen“ / „Später“)
- **WLAN-Empfehlung im lokalen Netz**: wer vorschlägt, ins lokale Netzwerk zu wechseln,
  schickt (wenn ermittelbar) den eigenen WLAN-Namen mit – die anderen sehen direkt,
  welches Netzwerk sie dafür brauchen
- Korrektur an der Release-Veröffentlichung selbst (Versionsnummer und
  Pre-Release-Markierung wurden beim allerersten Lauf nicht richtig gesetzt)

### Installation

1. `FloppyHubSetup-2.0.0-beta.2.exe` herunterladen und ausführen
2. Variante wählen, Zielordner frei wählbar, Autostart optional
3. Unbeaufsichtigt: `FloppyHubSetup-2.0.0-beta.2.exe /VERYSILENT /VARIANT=app` (oder `console`)
4. Schon installiert? Setup einfach erneut ausführen – Einstellungen und Bibliothek bleiben

### Gut zu wissen (Beta)

- Das Setup ist noch **nicht signiert**: Windows SmartScreen meldet eventuell
  „Computer geschützt“ → *Weitere Informationen* → *Trotzdem ausführen*
- ntfy.sh erlaubt ohne Konto etwa **250 Nachrichten pro Tag pro IP-Adresse**. Für lange
  Gespräche ins lokale Netzwerk wechseln
- Der Wechsel ins lokale Netzwerk braucht **dasselbe Netzwerk** auf beiden Seiten – die
  neue WLAN-Empfehlung im Vorschlag hilft, das zu erkennen
- Das Launcher-Log bleibt deutsch – wie bei der Konsolen-Variante

### Voraussetzungen

- Windows 10 / 11 (64 Bit)
- Konsole: Windows PowerShell 5.1 (bei Windows dabei)
- Diskettenlaufwerk als `A:` (USB-Floppy genügt)

Die Prüfsumme der EXE steht in der beiliegenden `.sha256.txt`.
